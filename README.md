# HVAC Oil / Rack Checklist (Educational)

Python **stdlib-only** interactive commercial rack oil call tree: separator ΔP, filters, float/level regulators, EPR stability, oil traps, oil-logging signs.

> **Educational only — OEM rack controls vary.**

## Quick start

```bash
cd hvac-oil-rack-checklist
python3 oil_rack_checklist.py -i
python3 oil_rack_checklist.py --symptom low-oil-alarm
```
